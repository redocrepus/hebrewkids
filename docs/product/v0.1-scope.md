# v0.1 Scope

## Use Case 1: Word-building lesson
- **Prompt**: Show word image, play target audio automatically; allow replay.
- **Interaction**: Present empty answer boxes sized per syllable. Provide scrambled syllable tiles that support drag-and-drop or tap-to-place (tap selects tile, tap on next open box to place; tap again to unplace).
- **Feedback**: Play syllable audio on tile tap; after all tiles placed, play assembled word audio in order, then success animation/sound.
- **Progression**: Auto-advance to next word after success animation or via explicit Next CTA.
- **Error states**: If media fails, show inline retry + fallback text prompts.

## Use Case 2: Add word
- **Form fields**: word text, optional transliteration, language, tags, difficulty, syllable helper (auto split + manual edits), upload image, audio generation via TTS (default) with fallback to record/upload.
- **Validation**: Require word text and at least one syllable; ensure media attached (TTS or recording) before submit.
- **Storage**: Persist Word, Syllables, MediaAsset; scope user-created content to owner via auth + RLS.
- **Preview**: Show preview card (image + audio) before saving.

## UX inspiration
- Mirror the reference app: large touch targets, bright cards, sticky audio replay button, tactile drag-drop with snapping, celebratory checkmark animation, and upbeat success chime.
- Keep layouts thumb-friendly for tablets and phones; support both drag-drop and tap-to-place for accessibility.

## Acceptance tests
1. **Audio playback**: word audio auto-plays on prompt; replay button works; tile tap plays syllable audio. Media failures show retry + fallback text.
2. **Drag-drop / tap-to-place**: tiles draggable and tappable; placed tiles snap into boxes and can be unplaced.
3. **Success animation**: on correct ordering, play syllable sequence then success animation and chime.
4. **Next-word advance**: auto-advance after success or via Next button; progress indicator updates.
5. **Add-word form**: validates inputs; supports image upload; defaults to TTS audio; allows manual record/upload fallback when TTS fails.
6. **TTS fallback to recording**: simulate TTS failure to confirm UI offers recording/upload path and successful submission persists media reference.
