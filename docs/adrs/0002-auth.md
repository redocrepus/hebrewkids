# ADR 0002: Auth Approach

- **Decision**: Phase 1 local username/password; Phase 2 Google OIDC with account linking.
- **Context**: Early pilot with small cohort; need fast setup without email infra but roadmap to SSO.
- **Consequences**:
  - Password hashing via Argon2id/bcrypt; short-lived session JWT + refresh cookies.
  - RLS for user-owned data enforced in database.
  - Later add Google provider table and linking flow without breaking existing accounts.
